## **Step 7: Connect Website & Schema** (Technical - 10 minutes)

### **Claim Your Website in GBP**

1. In GBP dashboard, click **Settings**
2. Add website: **https://mapletechlabs.ca**
3. Verify ownership (via domain meta tag or Google Analytics)

### **Ensure LocalBusiness Schema on Homepage**

Your homepage should include this schema (already in code from fixes):

```json
{
  "@context": "https://schema.org",
  "@type": "LocalBusiness",
  "name": "Mapletech Labs",
  "image": "https://mapletechlabs.ca/logo.png",
  "description": "Custom software development company...",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "[Office Address]",
    "addressLocality": "Edmonton",
    "addressRegion": "AB",
    "postalCode": "T5J 1B9",
    "addressCountry": "CA"
  },
  "telephone": "+1-403-604-8692",
  "url": "https://mapletechlabs.ca",
  "openingHoursSpecification": [
    {
      "@type": "OpeningHoursSpecification",
      "dayOfWeek": ["Monday", "Tuesday", "Wednesday", "Thursday", "Friday"],
      "opens": "09:00",
      "closes": "18:00"
    }
  ]
}
```
